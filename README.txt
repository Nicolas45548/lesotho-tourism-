LESOTHO TOURISM WEBSITE
========================

Beginner-friendly HTML5 + CSS3 + Bootstrap 5 + JavaScript project.

PAGES
-----
index.html
about.html
destinations.html
accommodation.html
activities.html
gallery.html
contact.html

FOLDERS
-------
css/style.css
js/script.js
images/

FEATURES
--------
- Semantic HTML5 elements
- Responsive Bootstrap 5 navbar and grid
- Cards
- Accordion
- Alerts
- Badges
- Forms
- Search
- Filtering
- Dark/light mode
- LocalStorage
- Booking cost calculator
- Image gallery next/previous controls
- HTML5 and JavaScript form validation

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open index.html in a browser.
3. Keep all folders together.
4. For GitHub Pages, upload the whole project to a GitHub repository.
